# React Todo App

A modern and responsive Todo List application built with React.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Filter tasks:
  - All
  - Active
  - Completed
- Task statistics:
  - Total Tasks
  - Completed Tasks
  - Remaining Tasks
- LocalStorage persistence
- Responsive design

## Technologies

- React
- JavaScript (ES6+)
- CSS3
- Vite
- React Icons
