## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Undo completed tasks
- Filter tasks:
  - All
  - Active
  - Completed
- Display task statistics:
  - Total Tasks
  - Active Tasks
  - Completed Tasks
- Responsive design for different screen sizes

## Technologies

- React
- JavaScript (ES6+)
- CSS3
- Vite
